Arduino File: ThrustStand_Arduino.ino\
Web Interface: ThrustStand_WebInterface.html

See documentation here: https://docs.google.com/document/d/1Ft33sn2yKgaCtt8PaQJaWIB9m4Go_OUXZHSPiyGuBLQ/edit?tab=t.0

Key Features
* For testing electric propulsion systems
* Measures thrust of electric motor and propellor (up to 10kg)
* Measures power consumption (voltage, current, power)
* CSV data logging
* ESC speed control
* BLE connection to web-based serial monitor
